SMART PATH AUTO-DETECTION FEATURE DETAILS:
==========================================

How It Works:
-------------
1. Script checks if DEFAULT_PROJECT_PATH exists
   ├─ EXISTS → Use this path and proceed
   └─ NOT EXISTS → Try auto-detection

2. Auto-Detection Process:
   ├─ Get current script directory (%~dp0)
   ├─ Get parent directory
   ├─ Check for .apj files in parent directory
   ├─ IF FOUND → Use parent as project path
   └─ IF NOT FOUND → Show error with suggestions

3. Validation:
   ├─ Verify path exists
   ├─ Verify .apj files present
   └─ Provide clear feedback

User Benefits:
--------------
• Portability: Scripts work across different machines
• Flexibility: Works with both hardcoded and dynamic paths
• Safety: Validates before proceeding
• Clarity: Clear messages at every step
• Compatibility: Fully backward compatible

Use Cases:
----------
✓ Development environments with varying paths
✓ CI/CD pipelines with dynamic paths
✓ Team collaboration with different setups
✓ Multiple projects with same scripts
✓ Containerized build environments
